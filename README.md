# To-do list

Semplice web app per gestire le attività: aggiungi, completa, elimina e filtra per stato (Tutte / Da fare / Completate).

- Un unico file, senza dipendenze: `index.html`
- I dati restano salvati nel browser (`localStorage`)
- Interfaccia responsive pensata anche per il telefono, con tema chiaro/scuro automatico

## Uso

Apri `index.html` in un browser. Per averla online puoi pubblicarla con GitHub Pages.
